# Sort Algorithms Practice  

This repository is focused on learning and practicing sorting algorithms. It provides a practical way to grasp how various algorithms function, their efficiency, and their uses in the field of computer science.

## Purpose  
The main objective of this project is to enhance comprehension of sorting algorithms by implementing and experimenting with them.

## Implemented Algorithms  
The repository includes implementations of the following algorithms:  
- Bubble Sort  
- Selection Sort  
- Insertion Sort  
- Merge Sort  
- Quick Sort  
- Heap Sort
- Counting Sort
- Radix Sort
- Bucket Sort

An the following methods used as helpers for the mentioned before algorithms:
- genIntegerList
- genDoubleList
- mergeList
- quickSortPartition
- swap
- heapify
- getMaxValueOf
- countingSortBySignificantVals

~Note: Further information about the methods in javaDoc inside the code~
